## How we ship

One method, four gates. No heroics, no surprises.

1. **Scoping & Solution Design** (3-5 days) - goals, constraints and boundaries up front, then a fixed scope, timeline and budget to sign off on.
2. **Build** (4-8 weeks) - senior-only squads, weekly increments, a demo every week and a working build at all times.
3. **Test & Review** (every week) - every change clears automated tests, peer review and a security check before it merges. Quality is a gate, not a phase.
4. **Launch & Support** (ongoing) - staged rollout, monitoring, rollback plans and defined SLAs. We stay on after launch.
